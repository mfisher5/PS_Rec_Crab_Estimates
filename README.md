### Puget Sound Dungeness Crab Recreational Harvest Estimation 
*Last updated: 10/02/2026*

This repository includes the code and data used to generate harvest estimates based on reported CRCs. It also contains data and analyses that have been done with the Joint State-Tribal Shellfish Technical Working Group. The primary folder with code for generating the catch estimates from 2023 - 2025 are under the folder **Harvest Estimates**. All functions, data and input files are stored under the folders for the respective years. 
 
**Other files included in this repository include:** 
- **Partitioning Survey** - data and analysis used to produce the partitioning catch amoung Marine Areas to better align with the quota management areas used for harvest management. The partitioning survey data was used to produce the harvest estimates in 2024 and 2025.
- **Creel Data** - data from the Puget Sound Dungeness crab recreational creel project along with the associated metadata. On 10/2/2026 - code and creel data used for generating the 2025 EUC values was added.
- **Methods** - Resources and reports outlining methods used to produce Dungeness crab recreational catch estimates. 
- **Catch Memos** - Archive of Dungeness crab recreational catch memos produced annually by WDFW.
- **2023 RM Survey** - Data and processing code from the 2023 summer and winter non-respondent surveys conducted by *Responsive Management*.
